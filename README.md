## Example

A simple Python list:

```python
days = ["mon", "tue", "wed", "thu", "fri"]

print(days)
print(days[0])
print(days[-1])
```

Output:

```text
['mon', 'tue', 'wed', 'thu', 'fri']
mon
fri
```

Example of a list method:

```python
nums = [4, 5, 1, 7, 2]

nums.sort()

print(nums)
```

Output:

```text
[1, 2, 4, 5, 7]
```
