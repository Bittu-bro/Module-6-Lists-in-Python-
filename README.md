# Module 6 — Lists in Python 🐍

This module covers the fundamentals of **Lists in Python**, including creating lists, accessing elements, slicing, combining lists, repeating lists, and modifying list contents.

This module is part of my **Python learning journey**, where I am building my programming fundamentals step by step through practical examples.

---

## 📚 Topics Covered

- Creating Lists
- List Data Type
- Checking List Length using `len()`
- Accessing List Elements
- Positive & Negative Indexing
- List Slicing
- Combining Lists using `+`
- Repeating Lists using `*`
- Adding Elements using `append()`
- Adding Elements using `insert()`
- Adding Multiple Elements using `extend()`
- Removing Elements using `remove()`
- Removing Elements using `pop()`
